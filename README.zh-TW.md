# 快打旋風 6：USB 斷線後，畫面凍結怎麼辦？

[English](README.md)

如果你也遇到快打旋風 6 在 USB 斷線或無線滑鼠休眠後，還有聲音、畫面卻 freeze 的問題，可以試試 **SF6 USB Guard**。

[下載 ZIP](https://github.com/TANANIS/SF6-USB-Guard/archive/refs/heads/main.zip) · [使用說明](使用說明.md)

1. 解壓縮 ZIP，先關閉 SF6。
2. 開啟 **SF6-USB-Guard.exe**。
3. 按「**防護並啟動 SF6**」，程式會先檢查裝置，再套用防護並啟動遊戲。
